# EduGCC_Advisors

> 广州商学院 · 信息技术与工程学院 **导师/教师简历浏览页**
> 帮同学快速了解老师、辅助**选导师**。

打开 [`index.html`](index.html) 即可浏览（本地双击，或启用 GitHub Pages 在线访问）。

---

## 快速上手

1. 打开 `index.html`
2. 点左侧顶部 **★ 导师名单** —— 只显示可选的导师（按名单顺序）
3. 用搜索框找姓名/方向，或点左侧「栏目」按院系筛选
4. 点卡片查看完整简历、照片与**官网原文**

支持键盘：`←/→` 上一位/下一位，`Esc` 关闭。

---

## 功能

- **★ 导师名单（置顶板块）**：162 位导师集中展示，一目了然
- **栏目筛选**：教学名师、各系/教研室共 21 个栏目
- **关键词搜索**：按姓名或简介内容过滤
- **卡片简历**：照片 + 方向简介，点开看详情与官网原文
- **离线可用**：数据已内嵌，无需联网

## 目录结构

```
.
├── index.html          # 浏览页（打开这个）
├── src/                # 数据与图片
│   ├── teachers.json   # 结构化数据（姓名/栏目/日期/简介/图片）
│   ├── index.md        # 全院教师名录总表
│   └── <栏目>/<姓名>.md、<姓名>.jpg
└── scripts/
    ├── crawl_teachers.py    # 爬取学院官网教师简介与照片
    ├── compress_images.py   # 压缩照片（转 JPEG + 缩放）
    └── build_html.py        # 生成 index.html（含导师名单匹配）
```

---

## 更新数据

```bash
pip install requests pyquery pillow

# 1. 抓取官网教师简介与照片（--all = 全部栏目）
python scripts/crawl_teachers.py --all

# 2. 压缩照片（可选，减小体积）
python scripts/compress_images.py

# 3. 重新生成浏览页（改完 工作簿1.csv 后重跑此步即可）
python scripts/build_html.py
```
