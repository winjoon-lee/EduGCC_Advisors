[1]Boundary enhancement and refinement network for camouflaged object detection[J]. Machine Vision and Applications, 2024, 35(5): 107.

[2]曹慧贞，等人. 一种高鲁棒性的图像篡改检测方法.

[3]曹慧贞，等人. 基于多尺度跨层特征融合网络的伪装目标检测算法.

[4]曹慧贞，等人. 基于边缘细化和增强网络的伪装目标检测算法.
